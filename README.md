# ntnyq's skills

A curated collection of [Agent Skills](https://agentskills.io/home) reflecting [ntnyq](https://github.com/ntnyq)'s preferences.

## Installation

```bash
pnpx skills add ntnyq/skills --skill='*'
```

or to install all of them globally:

```bash
pnpx skills add ntnyq/skills --skill='*' -g
```

Learn more about the CLI usage at [skills](https://github.com/vercel-labs/skills).

- [`theme-color`](./skills/theme-color/SKILL.md) - Preserve semantic frontend colors across themes.

- [`unocss`](./skills/unocss/SKILL.md) - Configure and write UnoCSS in ntnyq's preferred style.
